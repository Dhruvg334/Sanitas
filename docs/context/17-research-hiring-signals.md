# External Research and Hiring Signals

Date researched: 2026-09-24

This document records why Sanitas emphasizes evidence, evaluation, reliability and production engineering.

## Abridge

Abridge describes its clinical AI around linked evidence and auditable AI that maps generated summaries to ground truth so providers can verify output.

Its current junior software engineering description includes:
- contributing to evaluation frameworks for accuracy, robustness and clinical reliability
- automated pipelines and human-in-the-loop review
- curiosity about model evaluation and failure modes
- judgment about where humans are critical

Its ML roles emphasize evidence extraction, evaluation techniques, experimentation, productionization and clinician feedback.

## Ambience Healthcare

Ambience's current Senior ML Engineer role explicitly emphasizes:
- evaluation pipelines
- automated graders and regression testing
- diagnosing production failure modes
- prompting, retrieval, context and routing interventions
- tracing and failure recovery
- observability
- end-to-end ownership

Its hiring philosophy also emphasizes clarity, accountability, trust, ownership and asking why.

## Interpretation for Sanitas

[Inference]
These hiring signals do not prove that any individual interviewer will prefer a particular stack. They do support a project strategy that demonstrates:
- measurable evals
- failure analysis
- evidence traceability
- production-oriented software structure
- observability
- human-verifiable output
- explicit trade-offs

Accordingly, Sanitas should not optimize for the number of trendy AI libraries used. It should optimize for the clarity and reliability of the system.
